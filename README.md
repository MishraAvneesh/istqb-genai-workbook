## How to Use

1. Open `index.html` in any browser (or visit your GitHub Pages URL)
2. Follow the Free LLM Setup section first
3. Work through projects in order — Ch1 → Ch2 → Ch3 → Ch4 → Ch5
4. Tick off tasks as you complete them (progress is saved in your browser)
5. Add your best prompts to `prompt-library.md` as you go

## Deploy to GitHub Pages

1. Fork or clone this repo
2. Go to **Settings → Pages**
3. Source: Deploy from branch → `main` → `/ (root)`
4. Save → wait ~2 minutes
5. Visit `https://YOUR_USERNAME.github.io/istqb-genai-workbook`
